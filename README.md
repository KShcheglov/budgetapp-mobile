# Мой Бюджет — мобильный просмотр

Статическая страница только для ЧТЕНИЯ (остатки денег по валютам, долги,
план/факт/остаток бюджета текущего месяца). Ничего не редактирует и не
пишет обратно — источник данных читает по ссылке из Dropbox, куда
десктопное приложение периодически кладёт снимок.

Иконка (`icons/icon-192.png`, `icons/icon-512.png`) — та же, что у
десктопного приложения (`backend/icon.ico` в основном репозитории),
просто пересохранена в PNG нужных размеров, для единого стиля между
десктопом и телефоном. Если десктопную иконку когда-нибудь поменяют —
стоит пересобрать и эти два файла из неё же.

## Шаг 1. Размести эту папку на бесплатном хостинге

Нужен именно https-хостинг (не просто открыть файл локально) — иначе
не заработают ни установка на главный экран, ни офлайн-кэш.

1. Заведи бесплатный аккаунт на [github.com](https://github.com), если
   его ещё нет.
2. Создай новый **публичный** репозиторий (например, `budgetapp-mobile`).
   Публичный — обязательное условие для бесплатного GitHub Pages, но
   репозиторий не содержит никаких твоих личных данных (это просто общий
   код страницы, ничего специфичного).
3. Через веб-интерфейс репозитория: **Add file → Upload files** — перетащи
   ВСЕ файлы из этой папки (`index.html`, `manifest.json`, `sw.js`, а
   также папку `icons/` целиком с обоими PNG внутри) **в корень**
   репозитория, не во вложенную подпапку — иначе страница не найдёт
   свои же файлы по относительным путям.
4. В репозитории: **Settings → Pages** (слева в меню) → в разделе
   "Build and deployment" выбери Source: **Deploy from a branch**,
   Branch: **main** (или `master`), папка **/ (root)** → Save.
5. Через минуту-две сверху появится ссылка вида
   `https://твой-логин.github.io/budgetapp-mobile/` — это и есть адрес
   твоей мобильной страницы.

(Не хочется заводить GitHub — подойдёт любой другой бесплатный
статический хостинг с https, например Netlify Drop: там просто
перетаскиваешь папку в браузере, без регистрации.)

## Шаг 2. Синхронизируй данные из десктопного приложения

1. В десктопном приложении: страница **"Резервные копии" → карточка
   "Мобильный просмотр"** → укажи путь к своей локальной Dropbox-папке
   → **"Синхронизировать для телефона"**. Можно также включить галочку
   "Синхронизировать автоматически при закрытии приложения".
2. Дождись, пока Dropbox на компьютере закончит загружать файл
   `budgetapp_mobile_snapshot.json` в облако (иконка синхронизации в
   трее должна успокоиться).
3. На сайте или в приложении Dropbox найди этот файл → **"Поделиться" /
   "Копировать ссылку"**. Если план Dropbox позволяет — включи пароль на
   ссылку: в файле остатки счетов и долги, у кого угодно с этой ссылкой
   без пароля будет к ним доступ.

## Шаг 3. Открой страницу на телефоне и настрой ссылку

1. В браузере телефона (Chrome на Android, Safari на iPhone) открой
   адрес со Шага 1.
2. Появится экран настройки — вставь туда Dropbox-ссылку с прошлого
   шага и нажми "Сохранить и загрузить".
3. Должны появиться три вкладки внизу экрана с реальными цифрами:
   Деньги / Долги / Бюджет.

## Шаг 4. Добавь на главный экран (необязательно, но удобно)

- **Android (Chrome):** три точки в правом верхнем углу → "Добавить на
  главный экран" / "Установить приложение" (иногда браузер сам
  предложит это баннером снизу).
- **iPhone (Safari):** кнопка "Поделиться" (квадрат со стрелкой вверх) →
  "На экран Домой".

После этого на столе телефона появится иконка "Бюджет" — открывается
как обычное приложение, без адресной строки браузера. Последние
загруженные данные также будут видны какое-то время без интернета
(пометка "офлайн — показаны последние загруженные данные").

## Дальше

Ссылку и настройку вводить заново не нужно — Dropbox-ссылка запоминается
в самом телефоне (localStorage браузера). При каждом открытии страница
сама подтягивает свежий снимок; если данные устарели — сначала сделай
новую синхронизацию на десктопе (кнопкой или автоматически при выходе,
если включил), потом жми "↻ Обновить" на телефоне.

Если понадобится сменить ссылку (например, старая просрочилась или
завёл новую Dropbox-папку) — внизу страницы есть "поменять ссылку".
